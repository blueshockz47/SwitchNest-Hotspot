# Windows alpha.1 (experimental FTP preview)

Install Python 3.11 or 3.12 x64 from python.org with Python launcher. Extract this branch ZIP, double-click start-windows.cmd. No administrator permissions needed. First launch installs Qt from PyPI. On later launches use `.venv\\Scripts\\python.exe -m v8.control_center` from checkout. Use an existing trusted local network, enter the actual Switch FTP IP and port. Windows Mobile Hotspot settings can be opened but the app does not configure offline isolation. Do not assume a Windows hotspot is offline; it may share internet. No DNS, firewall, hotspot startup, Sunshine or updater integration in this preview. Transfer metrics are per completed file on Windows. Use disposable files, not important SD content. Hardware and runtime validation pending. SteamOS branch is unchanged.
