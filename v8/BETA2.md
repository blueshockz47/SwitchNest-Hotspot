# Beta.2

Close SwitchNest before installing or switching releases. Extract a trusted repository ZIP, then run `bash install-switchnest-v8.sh` from that checkout as the ordinary desktop user. Internet is needed for PySide6 installation. The GUI is installed in ~/.local/share/switchnest/releases with a separate venv per release. Installation compiles source and runs FTP regression tests before activating it. KDE launcher uses the current pointer and no longer depends on Downloads. Existing QSettings and system hotspot configuration are retained. Existing v7.1 hotspot and panel helper are prerequisites for hotspot controls; this installer does not install or modify them. For a fresh host follow the root README's separate privileged installation steps.

Update: download/extract a newer trusted ZIP and rerun the installer. No automatic remote update or credential handling. Rollback: `cd ~/.local/share/switchnest/current && python3 -m v8.install rollback`. Status: same command with status. The first managed install has no managed previous version. Older releases remain on disk. Each upgrade requires disk space for another Qt environment. GUI runtime and SteamOS installation require hardware validation. Beta.1 source rollback: milestone/v8.0-beta.1.
