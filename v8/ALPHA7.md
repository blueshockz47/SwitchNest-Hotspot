# Alpha.7

Rollback: milestone/v8.0-alpha.6 (36fb449). Existing local PASV curl options unchanged. Test on disposable files and empty folders only. Long-press an entry for rename/delete; select a pane for new folder. Copy/Paste uses an internal clipboard and requires the source path and endpoint to stay unchanged. Drag individual files between panes; upload confirmation applies. History is session-only (last 100 finished transfer attempts). Statistics estimate bytes and mean speed using listing size and curl percentage; not exact wire counters. Remote MKD/RNFR/RNTO/DELE/RMD depend on FTP server support. Deletes are permanent, directories must be empty. Remote rename collision checks are based on the listing, not atomic. No recursive transfer or delete. Runtime tests pending.
